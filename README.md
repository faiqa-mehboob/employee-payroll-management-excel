
# Employee Payroll Management System

An Excel-based payroll system that calculates regular and overtime pay for 20 employees across multiple departments (HR, Finance, IT, Sales, Marketing, Operations, and more), based on hours worked and hourly rate.

## Features
- Automated overtime rate calculation (1.5x hourly rate)
- Regular pay and overtime pay computed per employee, rolling up to a total pay column
- Department-wise breakdown across 20 employees
- Summary section with total payroll, average pay, and highest/lowest total pay

## Tools Used
- **Microsoft Excel** — formula-driven calculations (multiplication, SUM), structured summary statistics
